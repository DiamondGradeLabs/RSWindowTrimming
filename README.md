# Rising World Window Trimming

This is a mod that trims windows in the Rising World Unity Version. 

## How does it work? 

The window trimming will measure the window in the game and automatically trim wall pieces around it. It does this by replacing the pieces you place the window in with smaller blocks. 

## Use

When placing window chunks make sure the window intersects the wall panel. The window will place then the trimming function will calculate the trimming that needs to be done and trim it.
